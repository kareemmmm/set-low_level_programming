# 0x13. C - More Singly Linked Lists (Part 2)

This repository contains the continuation of the assignments on singly linked list configurations utilizing the `listint_t` data structures in C.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Compilation on **Ubuntu 20.04 LTS** using `gcc` flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Code verified against the **Betty Style** checking scripts.

## File Breakdown

| File Name | Description |
| --- | --- |
| `lists.h` | Header file containing structures and system prototypes. |
| `8-sum_listint.c` | Computes the mathematical sum of all data parameters (`n`). |
| `9-insert_nodeint.c` | Adds a node safely at a specific targeted index element. |
| `10-delete_nodeint.c` | Cleans up and frees an indexed node structure. |
| `100-reverse_listint.c` | Reverses an array trajectory with memory and statement boundaries. |
| `101-print_listint_safe.c`| Safely handles looped structure configurations during stdout dumps. |
| `102-free_listint_safe.c` | Loops and releases memory allocations containing circular routes. |
| `103-find_loop.c` | Identifies exact node intersections within cyclic references. |
